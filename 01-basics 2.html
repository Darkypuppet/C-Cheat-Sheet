The Basics of C++

Program structure, variables, data types, input/output — everything you need before writing a single real program. Python comparisons included.

👋

Your First C++ Program

Hello World
main.cpp
#include <iostream> // like Python's "import" — gives us cout/cin using namespace std; // lets us write cout instead of std::cout int main() { // every C++ program starts here cout << "Hello, World!" << endl; return 0; // 0 = "everything went fine" }
Key differences from Python

Curly braces {} replace Python's indentation to define blocks.

Semicolons ; end every statement — forgetting one is the #1 beginner error.

main() is mandatory — the entry point of every C++ program.

#include is like import, but for C++ libraries called headers.

How to compile & run

C++ is compiled, not interpreted like Python. You turn source code into an executable first.

Using g++ (most common compiler):

g++ main.cpp -o hello ./hello

Or use an online compiler like godbolt.org or repl.it.

Variables & Declaration

Typed & Explicit
🐍 In Python you write x = 5 and Python figures out the type. In C++ you must declare the type upfront: int x = 5;
Declaration syntax
// syntax: type name = value; int score = 42; // whole numbers double price = 9.99; // decimal numbers (prefer over float) float temp = 36.6f; // less precise decimal (note the f suffix) char grade = 'A'; // single character — use single quotes! bool done = false; // true or false string name = "Alice"; // text — needs #include <string> // declare without value (contains garbage — be careful!) int uninitialised; // ⚠ avoid this unless you assign before reading // multiple variables of same type int x = 1, y = 2, z = 3;
auto — let the compiler infer the type (C++11+)
auto score = 42; // compiler deduces: int auto price = 9.99; // compiler deduces: double auto name = "Alice"s; // deduces: std::string (note the s suffix) // auto is handy but doesn't make C++ dynamically typed. // Once set, the type is FIXED — you can't reassign a different type.
const — like Python's constants (but enforced)
const double PI = 3.14159; const int MAX_LIVES = 3; // PI = 3.14; ← compile error! const can't be changed

Type casting — converting between types
int a = 7; double b = 2.5; // C-style cast (older, works but less safe) double result = (double)a / 3; // → 2.333... // C++ style cast (preferred) int rounded = static_cast<int>(b); // → 2 (truncates, doesn't round!) // ⚠ Integer division trap (same as Python 2!) int bad = 7 / 2; // → 3, NOT 3.5! double good = 7.0 / 2; // → 3.5 ✓

Input & Output

cin / cout
cout — printing to the terminal
#include <iostream> using namespace std; int main() { int age = 25; string name = "Alice"; cout << "Hello!\n"; // \n = newline cout << "Hello!" << endl; // endl = newline + flush buffer cout << "Name: " << name << "\n"; cout << name << " is " << age << " years old.\n"; }
cin — reading user input
int main() { int age; string name; cout << "Enter your name: "; cin >> name; // reads ONE word (stops at space) cout << "Enter your age: "; cin >> age; cout << "Hello, " << name << "! You are " << age << ".\n"; // To read a full line with spaces, use getline: string sentence; cin.ignore(); // clear leftover newline from cin getline(cin, sentence); // reads entire line including spaces }
⚠ Mixing cin >> and getline()? Always call cin.ignore() between them, or getline immediately reads an empty line. Classic beginner trap.

Strings — Quick Intro

std::string
Common string operations
#include <string> using namespace std; string a = "Hello"; string b = " World"; string c = a + b; // "Hello World" — concatenation with + a += "!"; // "Hello!" int len = a.length(); // or a.size() — same thing char ch = a[0]; // 'H' — 0-indexed like Python string sub = a.substr(0, 5); // "Hello" — (start, LENGTH), not (start, end)! bool empty = a.empty(); // true if "" // Find — returns string::npos if not found size_t pos = a.find("ell"); // → 1 if (pos != string::npos) cout << "Found at " << pos << "\n";
