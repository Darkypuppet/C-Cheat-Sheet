Object Oriented Programming

Classes, objects, constructors, inheritance. Same ideas as Python — stricter syntax, explicit access control.

Class — Basic Structure

Blueprint for objects
declaration — goes in a .h file or above main()
class Dog { public: // accessible from anywhere string name; int age; void bark() { cout << name << " says: Woof!\n"; } private: // accessible only inside the class string secret; }; // ← don't forget the semicolon! // create an object Dog d; d.name = "Rex"; d.age = 3; d.bark(); // Rex says: Woof! // Python equiv: // class Dog: // def bark(self): print(f"{self.name} says: Woof!")
⚠ Class members are private by default. struct members are public by default. That's the only real difference between them.

Constructor & Destructor

__init__ & __del__ equiv
same name as the class · no return type
class Dog { public: string name; int age; // constructor — runs when object is created Dog(string n, int a) { name = n; age = a; } // destructor — runs when object is destroyed ~Dog() { cout << name << " is gone.\n"; } void bark() { cout << "Woof!\n"; } }; Dog d("Rex", 3); // constructor called d.bark(); // destructor called automatically when d goes out of scope
initialiser list — cleaner constructor syntax
Dog(string n, int a) : name(n), age(a) {} // preferred — initialises members directly instead of assigning

Access Control

public · private · protected
getters & setters — the standard pattern
class BankAccount { private: double balance; // can't be touched from outside public: BankAccount(double b) : balance(b) {} double getBalance() const { return balance; } // getter void deposit(double amount) { // setter/action if (amount > 0) balance += amount; } }; BankAccount acc(100.0); acc.deposit(50); cout << acc.getBalance(); // → 150 // acc.balance = -9999; ← compile error! private
access levels
public: // anyone can access private: // only this class protected: // this class + // subclasses
const method
// const after () means // "won't modify the object" double getBalance() const { return balance; } // good habit for all getters

Static Members

Shared across all instances
belongs to the class, not the object
class Counter { public: static int count; // shared by all instances Counter() { count++; } }; int Counter::count = 0; // must define outside class Counter a, b, c; cout << Counter::count; // → 3 // Python equiv: class variable (not self.x, just x at class level)

Inheritance

Like Python's class B(A)
class Child : public Parent
class Animal { public: string name; Animal(string n) : name(n) {} void eat() { cout << name << " is eating.\n"; } }; class Dog : public Animal { // Dog inherits Animal public: Dog(string n) : Animal(n) {} // call parent constructor void bark() { cout << "Woof!\n"; } }; Dog d("Rex"); d.eat(); // inherited from Animal d.bark(); // Dog's own method // Python equiv: // class Dog(Animal): // def __init__(self, n): super().__init__(n)

virtual & Polymorphism

Override parent behaviour
virtual lets subclasses override a method
class Animal { public: virtual void speak() { // virtual = can be overridden cout << "...\n"; } }; class Dog : public Animal { public: void speak() override { // override keyword confirms intent cout << "Woof!\n"; } }; class Cat : public Animal { public: void speak() override { cout << "Meow!\n"; } }; // polymorphism — same call, different behaviour Animal* a1 = new Dog(); Animal* a2 = new Cat(); a1->speak(); // Woof! a2->speak(); // Meow!
💡 Always add a virtual ~Animal() {} destructor to base classes that use virtual methods — otherwise destroying a derived object via base pointer leaks memory.

Abstract Class

Pure virtual · Can't be instantiated
= 0 makes a method pure virtual
class Shape { public: virtual double area() = 0; // pure virtual — subclass MUST implement virtual ~Shape() {} }; class Circle : public Shape { double r; public: Circle(double r) : r(r) {} double area() override { return 3.14159 * r * r; } }; // Shape s; ← compile error! can't create abstract class Circle c(5); cout << c.area(); // → 78.5397 // Python equiv: ABC + @abstractmethod

struct

Like a class but public by default
used for simple data grouping
struct Point { double x, y; // public by default }; Point p = {3.0, 4.0}; cout << p.x << ", " << p.y; // 3.0, 4.0 // Python equiv: dataclass or namedtuple
