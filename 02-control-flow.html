Control Flow

Making decisions and repeating things — if, switch, for, while. Same ideas as Python, different syntax.

if / else if / else

Conditionals
syntax
if (condition) { // runs if condition is true } else if (other) { // runs if first was false, this is true } else { // runs if everything above was false }
example
int score = 72; if (score >= 90) { cout << "A\n"; } else if (score >= 70) { cout << "B\n"; // ← this one runs } else { cout << "C or below\n"; }
💡 Braces {} are optional for single-line bodies — but always use them. Skipping them causes classic bugs.

Ternary Operator

Inline if
condition ? value_if_true : value_if_false
int age = 20; string status = (age >= 18) ? "adult" : "minor"; // same as Python: status = "adult" if age >= 18 else "minor" cout << (score > 50 ? "pass" : "fail") << "\n";

switch

Match exact values
syntax + example
int day = 3; switch (day) { case 1: cout << "Monday\n"; break; // ⚠ without break, falls into next case! case 2: cout << "Tuesday\n"; break; case 3: cout << "Wednesday\n"; // ← this runs break; default: // like else — catches anything else cout << "Other day\n"; }
⚠ Always end each case with break. Without it, execution falls through into the next case — a very common bug. Python's match doesn't have this problem.
multiple values → same case (intentional fall-through)
case 6: case 7: cout << "Weekend!\n"; // runs for both 6 and 7 break;

for loop

Count-based
syntax — init ; condition ; increment
for (int i = 0; i < 5; i++) { cout << i << " "; // 0 1 2 3 4 } // Python equiv: for i in range(5): // count down for (int i = 10; i > 0; i--) { cout << i << " "; // 10 9 8 ... 1 } // step by 2 for (int i = 0; i <= 10; i += 2) { cout << i << " "; // 0 2 4 6 8 10 }

Range-based for loop

C++11 · Like Python's for x in list
for (type item : collection)
int nums[] = {10, 20, 30, 40}; for (int n : nums) { cout << n << " "; // 10 20 30 40 } // Python equiv: for n in nums: // use auto to avoid writing the type for (auto n : nums) { /* ... */ } // use const auto& for large objects (avoids copying) for (const auto& n : nums) { /* ... */ } // works on strings too string word = "hello"; for (char c : word) { cout << c << "-"; // h-e-l-l-o- }

while / do-while

Condition-based
while — checks first
int n = 0; while (n < 5) { cout << n << " "; n++; } // 0 1 2 3 4 // if n were already 5, // body never runs
do-while — runs at least once
int n = 10; do { cout << n << "\n"; n++; } while (n < 5); // prints 10 once — // condition checked AFTER // body runs. Note the ; at end
💡 Use while when you don't know how many iterations. Use for when you do. do-while is rare — mostly for menus or input validation.

break & continue

Loop control
KeywordWhat it doesPython equiv
breakExits the loop immediatelybreak
continueSkips rest of this iteration, goes to nextcontinue
example
for (int i = 0; i < 10; i++) { if (i == 3) continue; // skip 3 if (i == 7) break; // stop at 7 cout << i << " "; } // output: 0 1 2 4 5 6
