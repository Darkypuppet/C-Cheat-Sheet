Arrays & Strings

Fixed arrays, vectors (dynamic arrays), and full string manipulation. Python list and str comparisons throughout.

Raw Array

Fixed size · Stack allocated
declare · access · iterate
int nums[5] = {10, 20, 30, 40, 50}; // size MUST be known at compile time int zeros[5]; // ⚠ uninitialized — contains garbage int zeros[5] = {}; // all zeros ✓ nums[0]; // → 10 (0-indexed like Python) nums[4]; // → 50 (last element) nums[5]; // ⚠ out of bounds — undefined behaviour, no error thrown! // size of array int len = sizeof(nums) / sizeof(nums[0]]); // → 5 // loop for (int i = 0; i < 5; i++) cout << nums[i] << " "; for (auto n : nums) cout << n << " "; // range-based for — cleaner
⚠ Raw arrays don't know their own size and can't be resized. vector below fixes both — prefer it.

2D Array

Grid / Matrix
type name[rows][cols]
int grid[2][3] = { {1, 2, 3}, {4, 5, 6} }; grid[0][1]; // → 2 (row 0, col 1) grid[1][2]; // → 6 (row 1, col 2) for (int r = 0; r < 2; r++) for (int c = 0; c < 3; c++) cout << grid[r][c] << " ";

vector

Dynamic array · Like Python list
#include <vector>
#include <vector> using namespace std; vector<int> v = {1, 2, 3}; vector<int> empty; // empty vector vector<int> tens(5, 10); // {10, 10, 10, 10, 10}
common operations
v.push_back(4); // append — like Python's list.append() v.pop_back(); // remove last — like list.pop() v.size(); // number of elements — like len(list) v.empty(); // true if size == 0 v.clear(); // remove all elements v[0]; // access by index (no bounds check) v.at(0); // access with bounds check — throws if out of range v.front(); // first element v.back(); // last element // insert / erase by iterator v.insert(v.begin() + 1, 99); // insert 99 at index 1 v.erase(v.begin() + 2); // remove element at index 2 // iterate for (auto n : v) cout << n << " ";
💡 Always prefer vector over raw arrays unless you have a specific reason. It's safer, resizable, and works with all STL algorithms.

std::array

Fixed size · Safer than raw array
#include <array> · best of both worlds
#include <array> array<int, 3> a = {1, 2, 3}; a.size(); // → 3 (unlike raw array, it knows its size) a.at(0); // bounds-checked access a.fill(0); // set all elements to 0 // works with range-based for and STL algorithms

string

std::string · Like Python str
#include <string> · common operations
string s = "Hello, World!"; s.length(); // → 13 (also .size(), same thing) s.empty(); // true if "" s[0]; // → 'H' (char, 0-indexed) s.front(); // → 'H' s.back(); // → '!' // substring — (start, LENGTH) not (start, end)! s.substr(0, 5); // → "Hello" s.substr(7); // → "World!" (from index 7 to end) // find — returns string::npos if not found s.find("World"); // → 7 s.find("xyz"); // → string::npos // replace s.replace(7, 5, "C++"); // (start, length, replacement) → "Hello, C++!" // insert / erase s.insert(5, "!!"); // insert at index 5 s.erase(5, 2); // erase 2 chars starting at index 5 // concatenation string a = "Hello", b = " World"; string c = a + b; // "Hello World" a += "!"; // "Hello!"
compare strings
string a = "apple"; string b = "banana"; a == b; // false a != b; // true a < b; // true (alphabetical) // same as Python — == works fine
convert to/from numbers
// string → number int i = stoi("42"); double d = stod("3.14"); // number → string string s = to_string(42); string s = to_string(3.14); // like Python's int(), float(), str()
iterate over characters
string s = "hello"; for (char c : s) cout << c << "-"; // h-e-l-l-o- // modify in place — use reference for (char& c : s) c = toupper(c); // s becomes "HELLO"

stringstream

Parse & build strings
#include <sstream>
#include <sstream> // build a string like f-strings in Python int age = 25; stringstream ss; ss << "Name: Alice, Age: " << age; string result = ss.str(); // "Name: Alice, Age: 25" // parse space-separated values from a string string data = "10 20 30"; stringstream parser(data); int a, b, c; parser >> a >> b >> c; // a=10, b=20, c=30
