The STL

Standard Template Library — ready-made containers and algorithms. The toolbox that makes C++ practical.

Containers — Which to Use

Pick the right one

vector<T>Ordered list, fast random access, size changeslist
array<T,N>Fixed size, stack allocated, fasttuple (fixed)

map & unordered_map

Key-value · Like Python dict
#include <map> · #include <unordered_map>
#include <map> map<string, int> ages; ages["Alice"] = 30; // insert / update ages["Bob"] = 25; ages.insert({"Carol", 28}); // another way to insert ages["Alice"]; // → 30 (creates entry if missing!) ages.at("Alice"); // → 30 (throws if missing — safer) ages.count("Alice"); // → 1 if exists, 0 if not (like Python's in) ages.size(); // number of entries ages.erase("Bob"); // delete a key ages.clear(); // remove all // iterate — like Python's dict.items() for (auto& [key, val] : ages) { // structured binding (C++17) cout << key << ": " << val << "\n"; }
💡 Use unordered_map when you don't need sorted keys — it's significantly faster (O(1) vs O(log n) lookup).

set & unordered_set

Unique values · Like Python set
#include <set>
#include <set> set<int> s = {3, 1, 4, 1, 5}; // duplicates ignored → {1, 3, 4, 5} s.insert(9); s.erase(3); s.count(4); // → 1 if exists, 0 if not s.size(); for (auto n : s) cout << n << " "; // always in sorted order

stack & queue

LIFO · FIFO
stack — last in, first out
#include <stack> stack<int> st; st.push(1); st.push(2); st.push(3); st.top(); // → 3 (peek) st.pop(); // removes 3 st.empty(); // false st.size(); // → 2
queue — first in, first out
#include <queue> queue<int> q; q.push(1); q.push(2); q.push(3); q.front(); // → 1 (peek front) q.back(); // → 3 (peek back) q.pop(); // removes 1

pair & tuple

Bundle values together
#include <utility> · #include <tuple>
#include <utility> pair<string, int> p = {"Alice", 30}; p.first; // → "Alice" p.second; // → 30 auto p2 = make_pair("Bob", 25); // type inferred // tuple — more than two values #include <tuple> auto t = make_tuple("Alice", 30, true); get<0>(t); // → "Alice" get<1>(t); // → 30 // C++17 structured binding auto [name, age, active] = t; // like Python tuple unpacking

Algorithms

#include <algorithm>
sort · find · count · min · max · reverse
#include <algorithm> vector<int> v = {5, 2, 8, 1, 9}; sort(v.begin(), v.end()); // {1, 2, 5, 8, 9} ascending sort(v.begin(), v.end(), greater<int>()); // descending reverse(v.begin(), v.end()); // flip the order find(v.begin(), v.end(), 8); // iterator to 8, or v.end() if not found count(v.begin(), v.end(), 5); // how many times 5 appears min_element(v.begin(), v.end()); // iterator to smallest max_element(v.begin(), v.end()); // iterator to largest accumulate(v.begin(), v.end(), 0); // sum — needs #include <numeric> fill(v.begin(), v.end(), 0); // set all to 0 // check if any / all elements satisfy a condition any_of(v.begin(), v.end(), [](int n) { return n > 5; }); all_of(v.begin(), v.end(), [](int n) { return n > 0; });
⚠ Most algorithms work on iterators — v.begin() and v.end(). Think of them as Python's v[0] and one-past-the-end.

Iterators

Traverse any container
pointer-like objects that walk through containers
vector<int> v = {10, 20, 30}; // explicit iterator for (vector<int>::iterator it = v.begin(); it != v.end(); ++it) cout << *it << " "; // same thing with auto — much cleaner for (auto it = v.begin(); it != v.end(); ++it) cout << *it << " "; // in practice just use range-for for (auto n : v) cout << n << " "; // ← do this
