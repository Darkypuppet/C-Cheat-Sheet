Pointers & References

The most C++-specific topic. No direct Python equivalent — but once it clicks, everything else makes sense.

The Core Idea

Memory addresses
every variable lives at a memory address
int x = 42; cout << x; // → 42 (the value) cout << &x; // → 0x61ff08 (the address — where it lives in RAM) // & here means "address of" — not to be confused with reference &
💡 Think of memory as a street. Every variable is a house. The value is what's inside the house. The address is the street number. A pointer is a piece of paper with that street number written on it.

Pointers

type* · stores an address
declare · assign · dereference
int x = 42; int* ptr = &x; // ptr holds the ADDRESS of x cout << ptr; // → 0x61ff08 (the address) cout << *ptr; // → 42 (the value AT that address — dereference) *ptr = 99; // change the value through the pointer cout << x; // → 99 (x changed too — same memory!)
the two uses of * — don't confuse them
int* ptr; // * in declaration = "this is a pointer type" *ptr; // * in expression = "get the value at this address"
⚠ Always initialise pointers. An uninitialised pointer points to a random address — using it is a segfault waiting to happen.

nullptr

Like Python's None
a pointer that intentionally points to nothing
int* ptr = nullptr; // safe "empty" pointer — like None in Python // always check before using! if (ptr != nullptr) { cout << *ptr; } // or just: if (ptr) { cout << *ptr; } // nullptr is falsy, like None

References

Alias · Not a copy
type& — another name for the same variable
int x = 42; int& ref = x; // ref IS x — same memory, different name ref = 99; cout << x; // → 99 (changing ref changes x) // references must be initialised immediately — can't be null // references can't be reassigned to refer to something else
pointer vs reference
// Pointer int* p = &x; // can be null *p = 5; // needs * p = &y; // can point elsewhere // Reference int& r = x; // can't be null r = 5; // no * needed // r = y would copy y into x
when to use each
// Use reference when: // — you just want an alias or // to avoid copying in a function void print(const string& s) {} // Use pointer when: // — it can be null // — you need to change what // it points to // — working with dynamic memory

Dynamic Memory

new · delete · heap
allocate and free manually
// allocate on the heap int* p = new int(42); // single value int* arr = new int[10]; // array of 10 ints cout << *p; // → 42 arr[0] = 99; // ALWAYS free what you allocate delete p; // free single value delete[] arr; // free array — note the [] p = nullptr; // good habit after delete arr = nullptr;
⚠ Forgetting delete = memory leak. Using a pointer after delete = undefined behaviour. This is why smart pointers exist.

Smart Pointers

C++11 · Auto-managed · Prefer these
#include <memory>
#include <memory> // unique_ptr — one owner, auto-deleted when out of scope auto p = make_unique<int>(42); cout << *p; // → 42 // no delete needed — freed automatically // shared_ptr — multiple owners, freed when last owner gone auto s = make_shared<int>(99); auto s2 = s; // both point to same value cout << s.use_count(); // → 2 (two owners)
💡 In modern C++ you should almost never use raw new/delete. Use make_unique by default, make_shared when you need shared ownership.

Pointer Arithmetic

Moving through memory
pointers can be incremented like indexes
int arr[] = {10, 20, 30, 40}; int* p = arr; // points to arr[0] cout << *p; // → 10 p++; cout << *p; // → 20 p += 2; cout << *p; // → 40 // arr[i] and *(arr + i) are identical arr[2] == *(arr + 2); // true
