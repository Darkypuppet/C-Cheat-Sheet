C++ Keywords

One-line definitions. Flip here when you remember the concept but forget the word.

Reserved Keywords

Can't use as variable names
intWhole number type. 4 bytes.
doubleDecimal number. 8 bytes, 15 digits precision. Prefer over float.
floatDecimal number. 4 bytes, 7 digits precision. Less accurate.
charA single character. 'A', '3', '!' — single quotes only.
boolTrue or false. Written true / false (lowercase).
voidNothing / no type. Used for functions that return nothing.
constMakes a variable immutable — can't be changed after set.
autoLet the compiler figure out the type from the value.
returnExits a function and sends a value back to the caller.
ifRuns code only if a condition is true.
elseRuns code if the if condition was false.
else ifAdditional condition check after an if.
switchBranches on an exact value — cleaner than many if/else.
caseA branch inside switch. Needs a break to stop falling through.
breakExit a loop or switch immediately.
continueSkip the rest of this loop iteration, go to next.
forLoop with init, condition, increment in one line.
whileLoop that runs while a condition is true.
doLike while but runs the body at least once first.
classBlueprint for an object. Members are private by default.
structLike class but members are public by default.
publicAccessible from anywhere.
privateAccessible only inside the class.
newAllocates memory on the heap. Returns a pointer.
deleteFrees memory allocated with new. Forgetting = memory leak.
nullptrA pointer that points to nothing. Like Python's None.
thisPointer to the current object inside a class method.
staticShared across all instances of a class, or persists across calls.
namespaceGroups code under a named scope to avoid naming conflicts.
usingImports a namespace. using namespace std is most common.
templateWrite code that works with any type. Like Python generics.
try / catchHandle errors/exceptions without crashing. Like Python's try/except.
throwRaise an exception. Like Python's raise.
inlineHint to compiler to paste the function body instead of calling it.
virtualAllows a method to be overridden in a subclass.
overrideMarks that you're intentionally overriding a virtual method.
explicitPrevents accidental implicit conversions on constructors.
sizeofReturns the size in bytes of a type or variable.
typedefCreates a type alias. Old style — prefer using in C++11+.

Preprocessor Directives

Run before compile
#includePastes another file's content here. Like Python's import.
#defineCreates a macro — a text substitution before compile.
#pragma onceTells compiler to include this file only once. Prevents duplicates.
#ifdef / #endifConditional compilation — include code only if something is defined.

Common Headers

#include these
<iostream>cout, cin, cerr. Input and output to terminal.
<string>std::string. Text handling.
<vector>std::vector. Dynamic array — like Python's list.
<map>std::map. Key-value pairs — like Python's dict.
<set>std::set. Unique values, auto-sorted.
<algorithm>sort, find, min, max and more.
<cmath>pow, sqrt, abs, floor, ceil, sin, cos…
<cstdlib>rand, srand, exit, atoi. General utilities.
<fstream>ifstream, ofstream. Read and write files.
<sstream>stringstream. Treat a string like a stream (parse/build strings).
<limits>numeric_limits. Max/min values for any type.
<memory>unique_ptr, shared_ptr. Smart pointers — safer than raw new/delete.

Concepts & Terminology

Things people say
compiledSource code is translated to machine code before running. Unlike Python.
compilerThe program that does the translation. Common ones: g++, clang++, MSVC.
header fileA .h or .hpp file — declares functions/classes for other files to use.
source fileA .cpp file — where the actual code lives.
declarationTells the compiler a name exists without defining what it does.
definitionThe actual implementation — the full function or variable with its value.
scopeWhere a variable is visible and usable. Defined by { } braces.
stackMemory for local variables. Auto-managed, fast, limited size.
heapMemory for dynamic allocation (new/delete). Manual, slower, larger.
pointerA variable that stores a memory address instead of a value.
referenceAn alias for an existing variable. Not a copy, same memory.
memory leakAllocated memory that's never freed. Program slowly eats RAM.
segfaultCrash from accessing invalid memory. Common pointer mistake.
overloadingMultiple functions with the same name but different parameters.
constructorSpecial method that runs when an object is created.
destructorSpecial method that runs when an object is destroyed.
inheritanceA class reuses and extends another class. Like Python's class B(A).
polymorphismSame method name behaves differently per subclass.
STLStandard Template Library. Built-in containers and algorithms.
iteratorAn object that traverses a container element by element.
compile errorCode is wrong syntax — won't even build. Fix before running.
runtime errorCode builds fine but crashes while running.
undefined behaviourCode that's technically wrong but the compiler doesn't catch it. Dangerous.
