Functions

Reusable blocks of code. Same concept as Python — different syntax, stricter types.

Anatomy of a Function

Structure
return_type name(parameters) { body }
// return_type name ( parameters ) { body } int add (int a, int b) { return a + b; } // Python equiv: // def add(a, b): // return a + b // calling it: int result = add(3, 4); // result = 7
⚠ In C++, functions must be declared before they are used. Either define them above main(), or use a forward declaration.

void — no return value

Like Python with no return
use void when the function just does something
void greet(string name) { cout << "Hello, " << name << "!\n"; // no return needed } greet("Alice"); // Hello, Alice!

Parameter Passing

By value · By reference
by value — gets a copy
void doubleIt(int n) { n *= 2; // only changes copy } int x = 5; doubleIt(x); cout << x; // still 5!
by reference — modifies original
void doubleIt(int& n) { // note & n *= 2; } int x = 5; doubleIt(x); cout << x; // 10 ✓
💡 Pass large objects (strings, vectors) by const& to avoid copying without allowing modification: void print(const string& s)

Default Arguments

Like Python defaults
set defaults in the declaration
void greet(string name, string msg = "Hello") { cout << msg << " " << name << "\n"; } greet("Alice"); // Hello Alice greet("Alice", "Hi"); // Hi Alice // ⚠ defaults must be at the END of the parameter list

Function Overloading

No Python equiv
same name, different parameter types
int add(int a, int b) { return a + b; } double add(double a, double b) { return a + b; } string add(string a, string b) { return a + b; } add(1, 2); // calls int version → 3 add(1.5, 2.5); // calls double version → 4.0 add("Hi", "!"); // calls string version → "Hi!" // compiler picks the right one based on argument types

Forward Declaration

Use before defining
declare the signature at the top, define later
int add(int a, int b); // ← forward declaration (just the signature) int main() { cout << add(2, 3); // works even though add is defined below return 0; } int add(int a, int b) { // ← actual definition return a + b; }

Lambda Functions

C++11 · Anonymous functions
[capture](params) { body }
// Python equiv: lambda a, b: a + b auto add = [](int a, int b) { return a + b; }; cout << add(3, 4); // 7 // capture outside variables with [&] or [=] int factor = 10; auto multiply = [&](int x) { return x * factor; }; cout << multiply(5); // 50 // common use — inline with sort() sort(v.begin(), v.end(), [](int a, int b) { return a > b; }); // sort descending
💡 [] = capture nothing  ·  [&] = capture all by reference  ·  [=] = capture all by value

Recursion

Same as Python
function that calls itself
int factorial(int n) { if (n <= 1) return 1; // base case return n * factorial(n - 1); // recursive call } cout << factorial(5); // 120
